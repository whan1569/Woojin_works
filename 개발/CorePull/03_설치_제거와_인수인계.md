# 03. 설치·제거와 인수인계

## 1. 설치 범위 (검증용 관측 버전)

| 항목 | 작업 |
|---|---|
| Logical | corepull_controller 프로그램에 [C](src/corepull_controller.c), [H](src/corepull_controller.h) 배치 |
| Software Configuration | CPU의 .sw(Task 배치)에서 프로그램을 Cyclic #4 / 20 ms에 등록. 기종별 Task와 순서 확인 |
| HMI | Enable, Forward Time, Speed, Pressure, TEST를 전용 변수에 연결 |
| DataSource | Local.dso에 CorePullConfig 구조체 및 gCorePullTest 등록 |
| VirtualKeys | Enable/TEST 입력 연결 확인. TEST 실제 누름·해제 특성은 Watch로 확인 |
| 기존 공용 코드 | 이번 버전에서는 변경하지 않음 |

AS 논리 프로그램 생성만으로 CPU Task가 실행되지는 않는다. 이전 HMI 단계에서 숫자 항목이 '-'로 표시되고 Watch에서 대응 변수를 찾지 못했다. Software Configuration에 신규 프로그램을 등록하고 빌드/Transfer한 뒤 정상적으로 연결됐다고 확인했다. 최신 관측 버전도 별도로 빌드와 변수 연결을 확인해야 한다.

## 2. 설정 계약

| 변수 | 타입 / 역할 |
|---|---|
| CorePullConfig.Enable | BOOL, RETAIN |
| CorePullConfig.ForwardTime | UINT, RETAIN, 10 ms 단위 |
| CorePullConfig.Speed | INT, RETAIN, 기존 속도 스케일 |
| CorePullConfig.Pressure | INT, RETAIN, 기존 압력 스케일 |
| gCorePullTest | BOOL, non-RETAIN 요청. 초기화 시 0 |

HMI 속도·압력의 Value/Min/Max/Teach DataPoint는 UnitGroup이 호환되어야 한다. 기존 동적 최대값 제한을 유지하고 SCALED 및 기존 단위 그룹을 일치시키는 방식으로 컴파일 오류 7145를 수정했다. 신규 기종에서는 실제 PLC 저장값과 HMI 표시 스케일, C/H 타입/기호 일치 여부를 재확인한다.

## 3. 다른 프로젝트로 이식할 때

- 순수 상태 엔진은 그대로 유지하고 AS 전용 관측부의 전역변수/헤더/축 번호와 자료형을 해당 프로젝트에 맞춰 검토한다.
- 기종별 공용 데이터의 RETAIN 속성, 배열 크기, 스케일, 모드 값, 안전 모듈과 축/펌프 구성은 원본 정의와 대조한다.
- Software Configuration 및 HMI 연결을 추가한 뒤 빌드·Transfer하고 Watch를 확인한다.
- 실제 구동 승인·소유권 및 후속 모션 제한 인터페이스는 별도 설계·검증이 필요하다. 공용 제어기의 직접 덮어쓰기나 물리 DO 강제는 하지 않는다.

## 4. 제거 / 원복

정지·출력 차단이 확보된 유지보수 상태에서 프로젝트와 RETAIN 설정을 백업하고, 신규 HMI 바인딩 및 가상키 의존성을 먼저 제거하거나 기존 페이지를 복원한다. 이후 신규 Task의 .sw 등록을 제거하고 Logical C/H 프로그램을 분리한 뒤 전체 빌드 및 참조 검사, 승인된 절차에 따른 Transfer, 기존 기능 회귀 확인을 수행한다. RETAIN 메모리와 심볼 변경 영향을 별도로 확인한다.

현재 버전은 공용 축 제어 프로그램 및 금형 레시피 구조를 직접 변경하지 않기 때문에 원복 범위를 전용 Task·전용 설정·HMI로 좁힐 수 있다. 향후 실제 구동 연동을 추가하면 그 인터페이스 또한 함께 원복해야 한다.
