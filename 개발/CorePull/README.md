# Core Pull — 독립 Task 기반 특수 코어풀 포팅

> 2026-11-20 개발 기준 / B&R Automation Studio 4.12 / 20 ms Cyclic Task  
> **현재 단계: 관측·사전 검사 및 상태 제어기 구현. 실제 CO1 구동 승인·실행 연동 미완료.**  
> 장비에 실제 구동 명령을 쓰지 않는 검증용 스냅샷이다.

## 개요

구형 장비에 공정 특수 옵션으로 구현한 코어풀을 신형 제어 구조에 이식하기 위해, 기존 공용 축 제어 로직을 수정·복제하는 방식 대신 별도 C/H 모듈을 구성했다. 목적은 기능 추가와 제거가 쉬운 구조, 유지보수 경계의 명확화, 실장비 적용 전 소프트웨어 논리 검증이다.

핵심은 사출과 코어풀을 병렬로 수행하는 공정 요구를 만족하는 것이며, 형폐 완료나 사출 완료 자체를 구동 시점으로 오해하지 않는 것이다.

## 작성 코드

- [corepull_controller.c](src/corepull_controller.c) — 상태 제어, 장비 관측, 사전 검사, AS Task
- [corepull_controller.h](src/corepull_controller.h) — 입력·출력·상태·승인 인터페이스
- [test_corepull.c](tests/test_corepull.c) — PC 단위 테스트 (10건)

src의 두 파일은 2026-11-20 배포한 `corepull_two_files.zip`과 동일한 내용이다. 최신 코드 자체를 보존하되 실구동 기능이 완성됐다고 표시하지 않는다. 기존 회사 제어 파일 및 전체 프로젝트, 고객·설비 식별 정보는 포함하지 않았다.

## 상태 요약

- 이전 단계에서 HMI/Task 등록 후 값 연결 정상화 확인.
- 최신 C/H의 호스트 C90 빌드 및 상태 제어기 회귀 테스트 10/10 통과.
- 최신 C/H의 AS4.12 빌드·Transfer·실장비 관측 결과는 이 문서 시점에 확인되지 않음.
- 제어권 연결, 실제 축 구동 및 후속 시퀀스 동기화는 미완료. 관측값을 강제해 실행하는 방식 금지.
