# IOForge 배포 후 수정점

## 1. 기록 목적

IOForge의 핵심 기능 개발과 실제 생성 결과 검증을 완료한 뒤 사용자에게 배포했다.

배포 이후 변경사항은 성격에 따라 다음 두 가지로 구분한다.

| 구분 | 기준 |
|---|---|
| 기능 문제 수정 | 실제 생성 결과, 데이터 정합성 또는 장비 적용에 영향을 주는 수정 |
| 사용자 최적화 | 기존 기능은 정상 동작하지만 반복 작업과 수동 입력을 줄이기 위한 편의사항 업데이트 |

이 구분을 통해 프로그램의 필수 수정과 사용 편의성 개선을 같은 수준의 문제로 기록하지 않는다.

## 2. 기능 문제 수정

### 2.1 Module No. 시작 기준 보정

Module No. 자동 정렬의 시작값을 1에서 0으로 수정했다.

- 수정 전 시작값: `1`
- 수정 후 시작값: `0`
- 정렬 기준: CPU와 Powerlink Node의 물리적 Rack·Slot 순서

수정 후 전체 모듈 번호가 0번부터 순차적으로 배치되고 각 Slot과 채널 연결이 정상 대응하는 것을 확인했다.

### 2.2 Slot·채널 정합성 검증

카드의 물리적 Slot 순서와 생성되는 채널 연결을 다시 비교했다.

Module No.를 0번부터 물리 순서대로 배치한 산출물에서 1번 Slot의 채널은 1번 Slot에, 이후 채널도 해당 Slot에 정상 대응하는 것을 확인했다.

## 3. 사용자 최적화

### 3.1 Module No. 정렬 버튼

사용자가 모듈 번호를 하나씩 입력하지 않도록 `Module No. 정렬` 버튼을 추가했다.

카드 구성을 완료한 뒤 버튼을 누르면 전체 모듈 번호가 물리 순서대로 자동 정렬된다.

기대 효과:

- 반복 입력 시간 단축
- 번호 누락 및 중복 방지
- 노드 추가 후 전체 번호 재입력 제거
- 일정한 생성 순서 유지

### 3.2 X20 KEB 자동 생성 지원

사용자가 KEB 하드웨어 템플릿과 IO 연결을 직접 편집하지 않도록 X20 KEB 생성 기능을 추가했다.

KEB를 선택하면 검증된 속도 PDO와 `gSPump[].PLK` IO 연결이 자동으로 적용된다.

- RelativeLoad `0x2C50`
- ElectricalOutputPower `0x2C52`
- Controlword `0x6040`
- Statusword `0x6041`
- VelocityActual `0x606C`
- TargetVelocity `0x60FF`

생성된 ST3·ST4에서 `ServoDrive1`, `ServoDrive2`와 PDO 구성을 확인했고 ST3의 OD 생성도 확인했다.

### 3.3 Powerlink 필수 카드 자동 구성

각 Powerlink Node에 `X20BC0083`과 `X20PS9400`이 자동 표시되도록 했다.

두 카드는 노드의 필수 카드로 고정해 이동하거나 일반 카드를 앞쪽에 삽입할 수 없도록 했다.

기대 효과:

- 노드별 필수 구성 확인 용이
- 필수 카드 누락 방지
- 카드 Drag & Drop 과정의 작업 실수 방지

### 3.4 사용 중인 카드·신호 표시

현재 하드웨어 구성에서 사용 중인 카드와 신호를 Card Studio와 Signal Studio에서 청록색으로 표시한다.

저장된 Standard를 선택하지 않아도 현재 편집 중인 구성을 기준으로 표시되도록 했다.

### 3.5 카드별 복수 사용처

카드를 단일 카테고리가 아니라 `DI`, `DO`, `AI`, `AO`, `AT`, `DC`의 복수 사용처로 관리하도록 변경했다.

하나의 카드가 여러 신호 계열에서 사용될 수 있는 실제 구성을 반영하고, 호환되는 카드와 신호를 더 쉽게 찾을 수 있도록 했다.

## 4. 현재 상태

- 핵심 기능 개발 완료
- 실제 생성 결과 검증 완료
- 사용자 배포 완료
- 기능상 확인된 문제 수정 완료
- 현재 사용자 피드백을 반영한 편의사항 업데이트 진행 중

이후 변경사항도 기능 문제 수정과 사용자 최적화를 분리해 기록한다.
