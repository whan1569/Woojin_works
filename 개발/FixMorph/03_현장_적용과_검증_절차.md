# FixMorph 현장 적용과 검증 절차

## 1. 전체 적용 순서

FixMorph 변환 전에 카드와 FIX 저장소가 정상 상태인지 먼저 확보해야 한다.

1. 신형 모니터용 카드를 작업한다.
2. 기존 FIX 저장 파티션을 완전히 초기화한다.
3. 신형 모니터용 소프트웨어를 새로 설치한다.
4. 신형 환경에서 빈 FIX를 직접 생성한다.
5. 기존 장비에서 사용하던 구형 FIX를 준비한다.
6. FixMorph에 구형 FIX와 신형 빈 FIX를 입력한다.
7. 분석 결과와 경고 항목을 확인한다.
8. 새 모니터용 FIX를 생성한다.
9. 결과 FIX를 설비에 적용하고 저장한다.
10. 재부팅 후 FIX 유지 상태와 장비 동작을 검증한다.

## 2. 작업 전 확인

- 구형 FIX가 실제 기존 장비에서 사용하던 파일인지 확인한다.
- 신형 빈 FIX가 초기화 및 신규 설치를 마친 새 환경에서 생성됐는지 확인한다.
- 기종이 같은지 확인한다.
- 기계번호가 다르면 참조 이식임을 인지하고 작업한다.
- TH 기종은 `SPmotor`를 확인한다.
- TH450S는 `MA_FIX.OPT.SbOilHeatingValveType`을 확인한다.

## 3. 변환 결과 확인

FixMorph 분석 화면에서 다음 수량과 경고를 확인한다.

- 자동 이식 수량
- 이미 동일한 값의 수량
- 신형 신규 필드 수량
- 보호된 체크섬 및 하드웨어 매핑 수량
- 기종 불일치 여부
- 기계번호 차이 여부
- 자료형 변경 여부
- TH 기종 `SPmotor` 값

기종이 다르면 변환을 진행하지 않는다. 자료형이 다른 항목과 신형 전용 항목은 자동 이식하지 않는다.

## 4. 설비 적용 후 검증

변환 완료만으로 작업을 종료하지 않고 실제 저장과 재부팅까지 확인한다.

### 4.1 데이터 유지 확인

- 결과 FIX가 목록에 정상 표시되는지 확인한다.
- FIX를 불러오고 저장할 수 있는지 확인한다.
- 재부팅 후 선택한 FIX가 유지되는지 확인한다.
- 포텐쇼미터 및 주요 파라미터가 0으로 초기화되지 않는지 확인한다.
- `Default Fix-Data Loaded` 및 `Invalid Recipe Data` 알람이 발생하지 않는지 확인한다.

### 4.2 장비 동작 확인

- 수동 동작의 전진·후진 및 속도를 확인한다.
- 속도·압력·보정값이 기존 장비 기준으로 반영됐는지 확인한다.
- 보호 기능과 장비 옵션을 확인한다.
- 오일 히팅 밸브 설정을 확인한다.
- 실제 장착 모터와 `SPmotor` 설정이 일치하는지 확인한다.

## 5. 문제 발생 시 구분

### 5.1 FIX가 인식되지만 값이 맞지 않는 경우

구조체 경로, 자료형, 이식 제외 항목과 감사 CSV를 확인한다.

### 5.2 저장 또는 재부팅 후 데이터가 사라지는 경우

FixMorph 변환 결과만 반복 생성하지 않는다. 파티션 완전 초기화와 신규 설치가 실제로 완료됐는지 먼저 확인한다.

### 5.3 신형 신규 기능이 동작하지 않는 경우

구형 FIX에 없는 신형 전용 항목은 자동 이식되지 않는다. 신형 기본값과 기종별 필수 설정을 별도로 확인한다.

## 6. 완료 기준

- 신형 프로그램이 결과 FIX를 정상 인식한다.
- 저장 후 재부팅해도 FIX와 설정값이 유지된다.
- 기존 장비의 주요 운전값이 보존된다.
- 신형 하드웨어 매핑과 신규 필드가 유지된다.
- 수동 동작과 실제 생산 동작에 이상이 없다.
