# PLC I/O 매핑 및 제어 파라미터 검토

> 작업 주간: 2026-11-02 ~ 2026-11-06  
> 구분: 구조 추적·기술 설명 자료  
> 상태: **분석 및 정리 진행 중**

## 1. IMC510 화면 채널명과 PLC I/O의 관계

요구는 기존 채널명 옆에 **IMC510 모니터상의 채널명**을 병기하고, PLC I/O 매핑까지 검토하는 것이다.

논리적으로는 최소 네 단계가 구분된다.

~~~text
[HMI/IMC510 표시명]
      ↓ 명칭 대응
[PLC 논리 변수]
      ↓ 제어 코드상의 참조
[ConfigIO / 물리 모듈·채널]
      ↓ 물리 신호
[실제 센서·릴레이·밸브]
~~~

코드 검토에서는 입력·출력 처리 모듈의 역할을 파악했다. 예컨대 tk1i는 아날로그 입력 계통, tk1o는 기종별 출력, tk2i/tk2o는 DI/DO, tk4i/tk4o는 옵션 관련 호출 흐름을 다룬다. 다만 **HMI 표시명만으로 실제 모듈·채널 번호를 역산할 수는 없다.**

## 2. 확인 결과와 제안

- **확인된 범위:** 논리 변수에서 축 입력·출력으로 이어지는 코드 경로 일부
- **미확인 범위:** 모든 IMC510 채널명의 1:1 대응표, 실제 프로젝트 ConfigIO 및 장착 카드와 일치 여부
- **개선 제안:** 표시명 / PLC 변수 / 물리 모듈 / 채널 / 신호 극성 / 기능 / 검증상태를 한 행에서 확인하는 표를 사용

같은 기능명이 HMI, PLC, 회로도에 각기 다르게 표현될 수 있다. 매핑표는 **물리 I/O 자료와 실제 신호를 대조한 뒤** 확정해야 한다.

## 3. 제어 파라미터 기술 검토

| 파라미터 | 일반적인 제어 의미 | 확인해야 할 차이 |
| --- | --- | --- |
| 가속도 | 목표 속도까지의 속도 변화율/가속 프로파일 | 장비의 단위, 램프 생성 위치, 제한값 |
| 감속도 | 속도를 감소시키는 프로파일 | 정지 거리, 감속 시작 조건 및 하드웨어 응답 |
| VP 출력 지연 | 속도 제어에서 압력 제어로 전환할 때의 출력 타이밍 관련 설정 | 해당 기종의 VP 신호 정의·타이머 시작/종료 조건 |
| 형개완료거리 OFFSET | 형개 완료 판정 위치/허용범위의 보정값 | 부호, 기준 위치, 판정 비교식과 축 스케일 |
| S커브 시간 | 가감속 경계에서 가속 변화(저크)를 완만하게 하는 시간 | 보간 방식, 램프 시간과의 관계 |

**중요:** 위 설명은 일반적인 제어 원리를 정리한 것이며 특정 기종의 내부 계산식·단위 또는 추천 설정값을 확정한 내용이 아니다.

## 4. 기술적 견해 및 후속 수정점

1. **이름과 실물 분리:** 화면 채널명/PLC 변수가 비슷하다는 이유로 물리 결선을 확정하면 오진하기 쉽다.
2. **설정값과 적용값 분리:** HMI 레시피 값이 실제 축 파라미터로 복사되는 경로와 갱신 시점을 추적한다.
3. **동작 조건과 계측 분리:** VP 지연·형개 완료 OFFSET은 조건식과 실제 상태 전환 타이밍으로 검증해야 한다.
4. **매핑표 정합성:** 기종, HW 구성 버전, 옵션 유무에 따라 달라지는 채널을 명시한다.
5. **변경 검증:** 설정값 변경이 필요하면 장비 안전 범위와 승인 절차를 전제로 시험한다.

**결론:** 논리 구조와 파라미터 역할에 대한 기술 설명은 정리했으며, 실제 IMC510 채널명·물리 I/O 전수 대조 및 설정식 확정은 후속 작업이다.
