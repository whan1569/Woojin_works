# 01. 문제인식 — 노즐 전진 후 자동 시퀀스 정체

> 접수일: 2026-11-02
> 사건 ID: NOZZLE-SEQUENCE-20261102
> 구분: **PLC 축 완료 판정 또는 자동 STEP 전이 문제**
> 증거 상태: 현장 전달 / 소스 정적 확인 / 온라인 TRACE 미수집 / 원인 미확정

## 1. 현장 제보와 최신 정정

**최신 정정 내용이 우선한다.** 문제는 '노즐 전진완료 신호가 ON에서 OFF되지 않는 것'이라고 확정된 것이 아니라, **압력 조건을 충족한 것으로 보이는 상황에서도 자동운전이 노즐 전진 단계에 머물고 다음 공정으로 진행하지 않는 것**이다.

| 항목 | 현장 전달 | 현재 검증 수준 |
| --- | --- | --- |
| 노즐 터치압력 표시값 | 약 170bar | 화면 실제값이라는 설명, PLC 동시간 계측 미확인 |
| 노즐 전진완료 기준 | 약 160bar | 표시/설정 명칭과 실제 코드 변수 일치 여부 미확인 |
| 현상 | 노즐 전진에서 다음 자동 STEP으로 진행 안 함 | 현장 진술, 자동 STEP 실측 미확인 |
| 노즐 오프셋 | 조정했으나 개선 없음 | 오프셋 종류/실제 적용값 미확인 |
| 최초 표현 | '노즐 전진완료 안 떨어진다' | 의미를 **시퀀스 정체**로 정정했으므로 완료 신호 미해제 현상으로 단정하지 않음 |

## 2. 서로 다른 완료 개념

이 사건에서 적어도 두 단계의 완료는 구분해야 한다.

1. **노즐 축 내부 완료:** `AXdat[S_IU].Status == AX_STAT_NEG_END_POSITION`인가?
2. **자동 시퀀스 다음 단계:** 자동제어가 축 완료 및 기타 요구 조건을 충족했다고 판단하고 다음 STEP으로 갔는가?

압력 170bar와 기준 160bar가 표시상 존재한다고 해서 ① 또는 ②가 참이라고 확정할 수 없다. 위치·센서 타입·추가 승압 임계치·타이머·모드·다른 축/인터록 조건은 별도로 확인해야 한다.

## 3. 이 사건에서 우선 제외할 혼동

- **지난주 별도 사건:** 175→141bar 수준의 노즐 터치압력 최초 도달값 저하. 오늘 사건의 원인으로 합치지 않는다.
- **계량 배압:** 스크루 계량 중의 배압과 노즐 터치압력은 다르다.
- **노즐 압력 감시 알람:** 감시 옵션과 알람 경로가 존재하지만 '전진완료가 성립하지 않는 구간'에서는 해당 감시가 동작하지 않을 수 있으며, 자동 STEP 정체의 직접 원인인지 미확인이다.

## 4. 진단 질문

1. 노즐 축 `CtrStep`이 실제로 28/31/40/35/0 중 어디에 있는가?
2. 축 `Status`는 전진완료값 2인가, 이동 중·미정의 등 다른 값인가?
3. 자동 시퀀스는 어느 STEP을 대기하며 무엇을 요구하는가?
4. 압력 170bar를 읽는 값과 160bar 설정이 **실제 비교식의 동일 변수·동일 시점·동일 단위**인가?
5. 압력 외 위치/디지털 입력/추가 승압 조건/타이머 중 무엇이 미충족인가?
