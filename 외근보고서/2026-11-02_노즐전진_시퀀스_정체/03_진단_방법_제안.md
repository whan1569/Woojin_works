# 03. 진단 방법 제안 — 170bar 표시 상태에서 자동 STEP 정체

> 사건 ID: NOZZLE-SEQUENCE-20261102
> 상태: 진단 계획 / 온라인 로그·자동 STEP 맥락 미수집
> 주의: 2026-10-30 압력 형성 저하 사건과 데이터를 혼용하지 않는다.

## 1. 최소 확인 세 가지

현장 담당자에게 '170bar인데 160bar 기준을 충족해도 다음 STEP으로 넘어가지 않는다'는 순간에 다음 세 값을 우선 확보한다.

| 항목 | 변수/대상 | 의미 |
| --- | --- | --- |
| 노즐 제어 STEP | `AXdat[S_IU].CtrStep` | 노즐 축 자체가 계속 전진 중인가? |
| 노즐 축 완료 상태 | `AXdat[S_IU].Status` | `NEG_END_POSITION = 2`인가? |
| 자동운전 현재 STEP | 자동 시퀀스의 현재 단계 표시/변수 | 축은 완료됐지만 전체 공정이 대기 중인가? |

**이 세 값은 같은 시각에 측정한다.** 화면 압력만으로 축 Status/자동 STEP을 역산하지 않는다.

## 2. 노즐 축 자체가 완료되지 않은 경우

| CtrStep | 구체적 확인 |
| --- | --- |
| 28 | `AXdat[S_IU].As`, `REC_DATA.IU.NEG.Ss[0]`, `IU_FIX.NEG.Sstol`, `PhyIn.negDI1`, `NEG.Con.IStop`; 위치+압력 또는 위치+입력 중 어떤 경로인지 |
| 31 | `SensorType`, `negDI1`, `MA_FIX.OPT.SbNozzleBoostPressure`, `Ap`, `SpNP`, `Sptol`; 디지털/압력 분기별 비교 |
| 40 | `Ap`, `SpNP`, `Sptol`, `IU_FIX.GEN.Ssp` 동시 비교; **두 기준이 모두 만족됐는지** |
| 35 | `CtrTimer`, `IU_FIX.NEG.StTouch`, `NEG.Con.Stop`, `NEG.Con.IStop`; 지연 이후 종료로 연결되는지 |
| 92 | `CtrTimer`, `IU_FIX.NEG.StVOff`, `AXdat[S_IU].Valve`; 지연 후 실제 종료 여부 |
| 0 + Status≠2 | 종료 후 중간정지/외부정지, 센서 상태 재판정과 Status 변화를 확인 |

압력과 설정은 내부적으로 0.1bar 단위를 쓰는 변수들이 있으므로 화면 170/160과 직접 비교하지 말고 환산 후 확인한다.

## 3. 축은 완료됐는데 자동운전이 계속 노즐 전진에서 기다리는 경우

`CtrStep=0`, `Status=2`라면 노즐 축 내부 완료 조건의 미충족이 아니라 **자동 시퀀스의 대기/전이 조건**을 추적한다.

- `scn_auto.c` 약 2040~2095행: 축 Status와 `pDynPar[ax]` 방향 검사, 다른 AND/OR 조건 및 이전·다음 단계 확인.
- `dynclc.c` 약 820~945행: 축 동작 완료 검사와 대기/인터록 처리 전체.
- 현재 자동 STEP과 **다음 STEP으로 전이되는 조건식 전체**를 확보하고, 각 항의 TRUE/FALSE를 같은 시각에 기록.
- 필요한 다른 축 상태, 모드, 알람, 인터록, 완료신호의 갱신 주기·순서도 확인.

기존 검색에서 `NEG_END_POSITION` 참조가 발견된 사실은 **어느 자동 STEP이 왜 막혔는지**를 직접 증명하지 않는다. 주변 코드를 확인해야 한다.

## 4. 동일 시간축 TRACE 권장 항목

- 노즐 `CtrStep`, `Status`, `NEG.Con.Status/Start/Stop/IStop`, `MoveType`, `SensorType`
- 노즐 `Ap`, `As`, `Sp_act`, `IU_PAR.NEG.SpNP`, `IU_FIX.NEG.Sptol`, `IU_FIX.GEN.Ssp`
- `REC_DATA.IU.NEG.Ss[0]`, `IU_FIX.NEG.Sstol`, `PhyIn.negDI1`, `PhyIn.negDI2`, `SbNozzleBoostPressure`
- 전용 노즐 압력센서 사용 옵션과 실제 압력 원본
- 자동 사이클 현재 STEP, 대기 조건, 다음 STEP 및 전진완료 참조
- `MA_STAT.AbNozzleTouchPrsNormal`, 모니터링 옵션, 노즐압력 이상 알람 상태, `MMI_DATA.Mode` (보호/정지 영향만 확인)

가능하면 정상적으로 다음 STEP으로 진행된 주기와 정체 주기를 같은 조건·시간축으로 비교한다. 시퀀스 전환 순간을 놓치지 않도록 실제 태스크 주기를 고려한 읽기 전용 TRACE를 사용한다.

## 5. 결과별 판단

| 동시 관찰 결과 | 다음 조사 경로 |
| --- | --- |
| `CtrStep=28`, 압력 만족하지만 위치 미충족 | 실제 위치/센서 스케일·목표·허용오차 |
| `CtrStep=31`, 압력 만족해도 `negDI1=0` (DIG 방식) | 전진 센서 입력/배선 및 선택된 센서타입 |
| `CtrStep=40`, `Ap<Ssp` | 추가 승압 조건·설정·압력 원본 |
| `CtrStep=35` 또는 92에서 정체 | 지연 타이머·정지명령·주기 동작 |
| `CtrStep=0`, `Status≠2` | 종료 시 Status 설정·재판정 |
| `CtrStep=0`, `Status=2`, 자동 STEP 정체 | 자동 시퀀스 전이 조건/인터록·다른 축 |
| Status가 2로 전이되지만 곧 사라짐 | `CheckAxStatus`의 센서 타입별 재판정·위치/리미트 입력 |

## 6. 현재까지의 결론과 안전 기준

- 현장의 170bar/160bar 수치만으로는 **완료 조건 전체 충족이 입증되지 않았다**.
- 실제로 노즐 축 STEP이 멈춘 것인지, 자동 STEP이 멈춘 것인지 아직 구분되지 않았다.
- 프로그램 수정이나 오프셋·압력 강제 변경 이전에 읽기 전용 온라인 데이터로 실행 경로를 확인한다.
- 안전 인터록 우회·출력 강제·임의 압력 상향으로 다음 단계 이동을 시도하지 않는다.

**우선 확보 자료:** `CtrStep`, `Status`, 자동 현재 STEP. 이 세 값만으로 첫 진단 갈래가 정해진다.
