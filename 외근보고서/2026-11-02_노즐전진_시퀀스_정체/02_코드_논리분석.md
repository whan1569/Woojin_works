# 02. 코드 논리 분석 — 노즐 전진 종료와 자동 STEP 전이

> 사건 ID: NOZZLE-SEQUENCE-20261102
> 소스: `iu_con/iu_con.c`, `iu_con/ax_func.c`, `tk1i_h/tk1i.c`, `alarm/alarm.c` 및 자동 시퀀스 검색 결과
> 상태: 정적 분석 중 / 온라인 상태·전체 자동 STEP 맥락 미확인
> 원본 회사 코드는 게시하지 않고 제어 분기 논리만 요약한다

## 1. 제어 층 구분

```text
[자동 시퀀스]
노즐 전진 명령 요청
     ↓
[노즐 축 제어 — iu_con]
CtrStep + SensorType + Ap/As/입력으로 종료 조건 확인
     ↓
[축 완료 기록 — ax_func]
ExitMoveNeg에서 정상 종료 시 Status = NEG_END_POSITION
     ↓
[자동 시퀀스]
축 Status·요청방향·다른 조건 확인 후 다음 공정으로 이동
```

`scn_auto.c` 약 2074행에는 `pAxDat[ax].Status == AX_STAT_NEG_END_POSITION` 및 `pDynPar[ax] == AX_DIR_NEGATIVE`를 함께 확인하는 코드가 검색된다. 하지만 **이 구간 전체와 사용자 화면의 '노즐 전진' 단계의 정확한 연결**은 아직 확인하지 못했다.

## 2. 노즐 축 주요 STEP과 정체 가능 조건

| CtrStep | 이름 | 코드에서 확인할 핵심 |
| --- | --- | --- |
| 26 | `SET_NORMAL_MOVE_NEG` | 이미 압력이 기준 이상인지 조기 종료 분기 |
| 28 | `NORMAL_MOVE_NEG` | 위치 조건 + 압력 또는 위치 + 전진 센서 입력 |
| 31 | `DIGITAL_MOVE_NEG` | 센서 타입에 따른 `negDI1` / 압력 도달, Boost 옵션 |
| 40 | `DIGITAL_MOVE_NEG_PRESSURE` | 두 압력 기준을 모두 만족하는지 |
| 35 | `PRESSURE_DELAY` | 설정된 지연 타이머 종료 여부 |
| 92 | `VALVE_DELAY_NEG` | 밸브 OFF 지연 종료 후 `ExitMoveNeg` |
| 0 | `STOPPED` | 축 제어 자체는 정지. `Status`가 완료인지 별도 판단 |

센서 방식은 초기화 시 `IU_FIX.GEN.SSensorType`에서 `AXdat[S_IU].SensorType`으로 복사된다. 실제 설정값은 모른다.

### 2-1. 위치센서 방식에서 압력 충족만으로는 완료되지 않을 수 있음

`iu_con.c` 일반 전진(약 670·684행)에서 정상 종료 조건은 다음 두 가지 경로로 구성된다.

- **실제 위치가 전진 목표 위치 허용범위에 도달**하면서 압력이 `SpNP - Sptol` 이상
- 또는 **실제 위치가 목표위치에 도달**하면서 `negDI1`이 유효

따라서 **Ap=170bar ≥ 표시 기준 160bar**라고 해도 `As`, `Ss[0]`, `Sstol`이 맞지 않으면 `CtrStep=28`에서 계속 머무를 수 있다.

### 2-2. 디지털 센서 방식에서 접점과 옵션에 따라 다름

`F_STEP_DIGITAL_MOVE_NEG`에는 다음 분기가 있다.

- DIG1/DIG2: `PhyIn.negDI1`이 유효해야 승압 지연 진입
- DIG_TIME: `SbNozzleBoostPressure`가 OFF면 `Ap >= SpNP - Sptol`; ON이면 먼저 `Ap >= IU_FIX.GEN.Ssp`가 되어야 추가 승압 STEP 40으로 진입
- PRESSURE: `Ap >= SpNP - Sptol`로 승압 지연 진입하는 코드 경로가 있다. 다만 초기 센서 타입 검증 허용값과 호환성 확인 필요

### 2-3. 추가 승압 STEP의 두 조건

`F_STEP_DIGITAL_MOVE_NEG_PRESSURE` (40)은 다음을 **AND**로 평가한다.

```text
(Ap >= IU_PAR.NEG.SpNP - IU_FIX.NEG.Sptol)
AND
(Ap >= IU_FIX.GEN.Ssp)
```

따라서 실제 170bar에 기준 160bar로 보이더라도 `IU_FIX.GEN.Ssp`가 170bar보다 높다면 STEP 40에서 정체할 수 있다. **이것은 조건식으로 가능한 설명이지 실제 현장 설정값이 그렇다는 증거는 아니다.**

### 2-4. 시작 시 조기 종료·완료 상태 재판정

`F_STEP_SET_NORMAL_MOVE_NEG`에서는 `Ap >= SpNP - Sptol`이면 초기 전진 진행 없이 `ExitMoveNeg()`를 호출할 수 있다. 해당 분기에서 POT 위치 조건을 검사하는 if/else가 **양쪽 모두 같은 종료 함수**를 호출한다. 따라서 그 특정 조기 종료 분기의 위치 판정은 종료를 제한하지 못한다.

`ExitMoveNeg()`는 `NEG.Con.Stop == 0` 및 `NEG.Con.IStop == NONE`인 경우 `Status = AX_STAT_NEG_END_POSITION`으로 기록할 수 있다. 후퇴·센서 상태 재판정은 `CheckAxStatus()` 등이 담당한다.

`Status == 2`여도 자동 시퀀스 전체 조건이 참이란 보장은 없다.

## 3. 터치압력 모니터링은 축 종료 판정과 별개

`tk1i.c`는 감시 옵션 ON + AUTO/SEMI_AUTO + **축 전진완료 상태**일 때 노즐 압력 `Ap/10`을 설정된 Min/Max와 비교하여 `MA_STAT.AbNozzleTouchPrsNormal`을 설정한다.

비정상이면 `alarm.c`에서 노즐 압력 이상 알람 SET; 해당 알람의 **기본** 반응에는 AUTOSTP가 포함된다. 이 감시 결과가 직접 `CtrStep=28/31/40`을 종료시키는 코드는 확인되지 않았다.

따라서 오늘처럼 **애초에 축 전진완료가 되지 않는 상황**에서는 이 감시를 켰다는 사실이 전진완료를 만들어주지 않는다. 알람으로 인한 모드 변경이 자동 STEP 정체를 일으켰는지는 별도로 검증해야 한다.

## 4. 미확인 사항 및 정적 코드에서 확정할 수 없는 것

- 현장의 `S_IU`, `SensorType`, `CtrStep`, `Status` 실제값
- 표시 170bar의 압력 원본과 실제 같은 시점의 PLC 내부 비교 데이터
- 전진 기준 160bar가 `SpNP`인지 추가 압력 설정값인지
- 자동 시퀀스 현재 STEP 및 필요한 모든 전이 조건 (자동 STEP 코드의 전체 주변 문맥)
- 위치센서 실제값·디지털 입력 및 정지명령·인터록 상태
- 체크밸브 교체 이력이 오늘 사건에 해당하는지 여부 (별도 10월 사건에서만 전달된 내용)

**결론:** 오늘 사건은 먼저 `노즐 축 내부 정체`와 `축은 완료되었지만 자동 시퀀스 정체`로 나누어야 한다. 판정의 1차 분기점은 `CtrStep`과 `Status`의 실제 온라인 값이다.
