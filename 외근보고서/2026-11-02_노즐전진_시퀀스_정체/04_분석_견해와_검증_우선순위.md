# 04. 분석 견해와 현장 검증 우선순위

> 사건 ID: NOZZLE-SEQUENCE-20261102  
> 기준: 2026-11-06 주간 정리  
> 상태: **정적 코드 분석 완료 / 현장 실행 경로 검증 필요**  
> 기존 문서: [문제인식](01_문제인식.md) · [코드 논리분석](02_코드_논리분석.md) · [진단 방법](03_진단_방법_제안.md)

## 1. 이번 주 분석 성과

현장 설명은 '표시 압력은 약 170bar이고 설정은 약 160bar인데, 노즐 전진 후 자동운전이 다음 STEP으로 이동하지 않는다'는 것이다. 이 수치가 **프로그램에서 비교하는 동일 변수·동일 단위·동일 시점의 압력**임은 확인되지 않았다.

기존 분석에서는 축 제어 내부 완료와 자동 시퀀스 STEP 전이를 분리했고, 압력 외의 **위치·전진 센서·추가 승압 설정·타이머·상태 재판정·자동 인터록**을 가능한 분기 조건으로 추출했다. 노즐 압력 저하를 다룬 10월의 별도 사건과 본 건은 혼합하지 않는다.

## 2. 핵심 판단: 고장을 두 갈래로 나눠야 한다

### A. 노즐 축 자체가 완료되지 않은 경우

- 축 CtrStep이 28이면 위치 및 압력/센서의 결합 조건을 먼저 비교한다.
- 31이면 센서 타입과 디지털 입력, 압력 완료 판정 경로를 구분한다.
- 40이면 기본 전진 압력과 추가 승압 기준의 **동시 만족** 여부를 본다.
- 35 또는 92이면 지연 타이머와 종료 호출, 정지 조건을 확인한다.
- 종료 처리 뒤 Status가 완료 상태로 설정되거나 유지되는지도 살핀다.

**견해:** 압력 하나가 설정 이상이라는 화면 정보만으로 축 완료 미성립을 코드 버그라고 판단하면 진단 방향이 잘못된다.

### B. 축은 완료됐지만 자동 공정이 정체한 경우

- 축 상태가 완료이고 CtrStep이 종료된 경우에도 자동 STEP의 다른 대기 조건은 미충족일 수 있다.
- 자동 현재 STEP, 완료 조건식의 전체 AND/OR 구성, 타축 상태·인터록·알람·운전 모드를 확인한다.

**견해:** 다음 STEP 전이가 발생하지 않는 현상만으로 노즐 축 제어 코드가 정체됐다고 단정하지 않는다.

## 3. 현장 검증 우선순위

| 우선 | 동시 관측 대상 | 판별 목적 |
| --- | --- | --- |
| 1 | 노즐 CtrStep / 노즐 Status / 자동 현재 STEP | 축 정체인지 공정 정체인지 분리 |
| 2 | 실제 압력 원본, 설정 압력, 단위·허용오차 | HMI 표시와 판정식의 동일성 확인 |
| 3 | 실제 위치, 목표위치, 센서 타입, 전진 입력 | 압력 이외 완료 조건 판정 |
| 4 | 추가 승압 옵션·임계치와 지연 타이머 | 특정 중간 STEP 정체 여부 |
| 5 | 정지/인터록/알람 및 자동 전이 전체 조건 | 완료 상태 상실 또는 공정 대기 원인 추적 |

가능하면 **정상 주기와 정체 주기의 동일 시간축 TRACE**를 비교한다. 자동 STEP 전환 직전/직후의 값을 확보하는 것이 중요하다.

## 4. 수정 검토 기준

- 실행 중 어느 조건이 거짓이었는지 확인하기 전에는 임의 압력 상향, 타이머 축소, 상태 강제 완료 또는 인터록 우회를 수정안으로 채택하지 않는다.
- 실제로 코드 결함이 확인되면 조건식뿐 아니라 Status 갱신, 우선순위, 다음 STEP 소비 시점까지 함께 회귀검증한다.
- 수정 전후 동일 레시피·운전 모드에서 재현성 및 정상 종료 경로를 비교한다.

## 5. 완료의 의미와 남은 작업

**완료:** 관련 코드의 조건식과 의심 분기, 측정 변수 및 진단 절차 분석.  
**미완료:** 현장 실시간 변수 수집, 실제 원인 확정, 수정 적용 및 재운전 검증.

따라서 이 사건은 **'분석 완료 / 현장 검증 필요'**로 관리한다.
