# BMC 금형가열 제어 — 요구 분석과 전장 구조 검토

> 작업 시점: 2026-11-04  
> 대상: TH 계열 BMC 금형가열 설비  
> 상태: **기술 검토 및 자료 정리 완료**  
> 주의: 설비 개조·결선 변경·현장 가열 성능 검증을 완료했다는 뜻은 아님

## 1. 요구 및 관측 내용

기존 BMC 설비에서는 히터 전원을 투입하면 주 마그네트가 동작하는 것으로 설명되었지만, 신규 설비는 HMI의 금형가열 기능을 활성화해야 동작한다는 차이가 제기되었다.

고객 요구는 **별도 온도조절기와 SSR을 이용한 독립적인 금형가열 운영**이다. 아울러 약 100°C 도달 이후 재승온이 원활하지 않다는 주장이 있었으나 원인과 재현 조건은 검증되지 않았다.

## 2. 제어 구조를 분리해 검토

~~~text
[기존 개념] 히터 전원 투입 → 전원/마그네트 경로 → 온도조절
[신규 개념] HMI 기능 활성 → PLC 허용/주 마그네트 → SSR/가열 회로
[요구 개념] 별도 온도조절기 → SSR 스위칭 → 히터
                       ↑
            전원 인가 및 보호/차단 인터록은 별도 확인
~~~

- **온도조절기:** 센서값과 설정값에 따라 히터 제어 신호를 생성
- **SSR:** 제어 입력에 따라 히터 전력을 스위칭하는 실행 요소
- **주 마그네트/보호회로:** 히터 전원의 공급·차단 경로를 결정
- **PLC/HMI:** 기능 허용, 운전 모드, 알람 및 인터록을 관리할 수 있음

온도조절기를 독립 구성한다고 해도 **주 전력 경로가 닫히지 않으면 SSR만으로 가열을 보장할 수 없다.**

## 3. 확인된 자료와 남은 불확실성

확보한 자료는 Autonics 온도조절기 및 SSR 제어 출력·결선 관련 정보이다. 이는 개별 제어기와 SSR의 연결 검토에는 유용하나, **기존/신규 장비의 주 마그네트 실제 구동 회로를 대신 증명하지 않는다.**

검토 단계에서 다음을 확정하지 않았다.
- PLC가 주 마그네트를 직접 소유하는지, 별도 하드웨어 조건이 있는지
- 약 100°C 이후 재승온 불량이 히스테리시스·센서·출력·주전원 중 어디에서 발생하는지
- 독립 운전으로 변경했을 때 충족해야 할 모든 안전 인터록

## 4. 기술적 판단과 수정 방향

**우선 판단:** PLC 코드를 먼저 수정할 사안이 아니라, 기존/신규 장비의 **전원·마그네트·SSR·온도조절기·안전회로의 소유 관계**를 전장도와 실물로 대조해야 한다.

수정이 필요하다면 다음 순서를 권장한다.

1. 기존과 신규의 주 마그네트 여자 조건 및 HMI 기능 허용 경로 비교
2. 독립 온도조절기 사용 시 전원 공급·차단 책임과 과열 보호 수단 정의
3. 온도조절기 출력 형식과 SSR 입력 정격, 부하 정격 및 냉각 조건 확인
4. 가열/정지/재가열과 온도센서 이상 시 반응을 각 모드에서 검증
5. 전장 변경이 확정된 이후에만 PLC 소유 기능과 인터록을 조정

임의의 마그네트 강제 여자 또는 안전 차단 경로 우회는 검토안에 포함하지 않는다.

## 5. 결과

- 요구사항을 **독립 온도제어**와 **주전원 허용 구조**로 분해함
- 관련 온도조절기·SSR 결선 자료 및 전장 비교 항목 정리 완료
- 전장 담당자가 확인할 구체적인 회로·동작 비교 기준 제시

**완료 범위:** 기술 검토·자료 정리.  
**별도 확인 필요:** 실제 결선 변경 여부, 100°C 재승온 현상, 운전 검증 결과.

검토 문서 작업은 **완료**로 기록한다.
