# 02. 해당 코드 논리 분석 — 노즐 터치와 전진완료 상태

> 분석일: 2026-11-02  
> 대상: B&R Automation Studio 기반 사출기 제어 로직  
> 범위: 현장에서 제공한 표시값 복사부, 노즐 축 제어부, 공통 축 상태 함수  
> 상태: **정적 코드 분석 완료(일부) / 온라인 상태·신호 매핑 미검증**  
> 주의: 공개 저장소 원칙에 따라 원본 회사 소스는 게시하지 않으며, 아래는 확인된 로직을 일반화해 재구성한 설명이다.

## 1. 분석 목적

2026-11-02 현장에서 '노즐 터치압력 약 170 bar, 전진완료 기준 약 160 bar, 오프셋 설정 후에도 전진완료 신호가 OFF되지 않음'을 보고하였다. 이 현상을 다음 질문으로 나눠 분석한다.

1. 화면의 노즐 터치압력값은 어떤 제어 데이터를 표시하는가?
2. 노즐 전진 종료·완료 상태는 어떤 조건에서 설정되는가?
3. 설정된 전진완료 상태는 어떤 조건에서 해제되는가?
4. '전진완료 신호'가 내부 축 상태인지 HMI 표시인지 외부 I/O인지 구별할 수 있는가?

## 2. 확인된 데이터 흐름

표시용 실제값 복사 태스크에서 각 축의 압력, 위치, 상태값은 축 제어 데이터에서 화면 인터페이스로 주기적으로 복사된다. 화면의 수치 자체가 완료 판정의 원본 로직을 갖는 것은 아니다.

```text
노즐 축 입력(전용 압력센서 또는 펌프 압력 피드백)
                  ↓
        노즐 축 실제 압력
                  ↓
        MMI용 실제값 복사
                  ↓
            HMI 압력 표시
```

노즐 축 압력원은 **전용 노즐 압력센서 사용 옵션**에 따라 바뀐다. 센서 사용 시 아날로그 입력을 스케일 변환하고, 미사용 시 지정 펌프의 압력을 참조한다. 어느 분기가 실제 가동 중인지는 미확인.

참고: 배압은 별도의 축 평균 압력 데이터이며 이 완료 판정에 혼용하지 않는다.

## 3. 전진 동작의 상태 전이

노즐 축은 일반 전진(NEG), 승압 판정, 압력 유지 지연, 밸브 OFF 지연, 종료의 상태기계로 구성된다.

```text
전진 시작 요청
    ↓
축 상태 = 전진 중, 방향 = NEG
    ↓
전진 밸브 ON / 펌프 요청
    ↓
센서 방식에 따른 전진 및 터치 조건 검사
    ├─ 압력 조건
    │   실제 노즐 압력 >= 승압 설정압력 - 압력 허용오차
    ├─ 위치 조건(해당 센서 경로)
    │   실제 위치 <= 전진 목표위치 + 위치 허용오차
    └─ 접점 입력 조건(해당 센서 경로)
    ↓
압력 지연 단계(적용 경로)
    ↓
전진 정지 처리 / 필요 시 밸브 OFF 지연
    ↓
정상 종료이면 축 상태 = 전진 끝 위치
```

- 일반 전진 중 일부 분기는 **위치 + 압력**이 동시에 맞거나, **위치 + 전진 리미트 입력**이 맞을 때 터치 판정으로 진행한다.
- 다른 분기는 센서 타입에 따라 압력만으로 진행하거나 전진 리미트 입력을 사용한다.
- 전진 요청이 들어왔을 때 실제 압력이 이미 완료 기준 이상이면, 일부 경로에서는 새 전진 동작을 수행하지 않고 곧바로 '전진 종료' 함수를 호출한다.
- 따라서 '160 bar 기준보다 170 bar로 높다'는 사실은 **완료 신호 OFF의 필요조건이 아니라 오히려 완료/종료 조건을 충족하는 상황**일 수 있다.
- 센서 입력의 단위는 내부적으로 0.1 bar 계열로 처리되는 코드가 있으므로, 화면 값과 설정값이 같은 스케일로 환산되었는지 온라인에서 검증해야 한다.

## 4. 완료 상태 SET 및 RESET 논리

### 4-1. 완료 상태 SET

공통 축 전진 종료 함수는 종료가 외부 Stop 명령 때문이 아니고 중간정지 조건이 없다면 'NEG 완료' 상태를 기록한다.

```c
// 원본 소스가 아닌 동작 개념을 설명하는 의사코드
if (forward_exit && !external_stop) {
    axis_status = intermediate_stop
        ? NEG_INTERMEDIATE_STOP
        : NEG_END;
}
```

**압력값을 계속 재검사하며 완료 상태를 결정하는 구조는 아니다.** 정상 종료 호출 시점에 완료 상태를 명시적으로 부여한다.

### 4-2. 완료 상태 RESET 또는 변경

공통 축 상태 점검은 설정된 센서 방식에 따라 달라진다.

| 센서 계열 | 기존 전진완료 상태의 해제/변경 조건 |
| --- | --- |
| 위치센서(POT/CAN 등) | 실제 위치가 전진 목표 위치 허용범위를 벗어나면 UNDEFINED로 전환 |
| 전진 리미트 입력(DIG 계열) | 전진 입력이 OFF되면 UNDEFINED로 전환 |
| 시간 기반 또는 압력 기반 일부 설정 | 공통 상태 점검 함수에서 별도 해제 분기를 확인하지 못함 |
| 후퇴 명령이 실제로 시작된 경우 | 후퇴 초기화 함수에서 축 상태를 POS_MOVEMENT로 전환 |

**결론:** 압력이 170 → 160 bar 아래로 내려간다는 것만으로 '완료 OFF'가 보장되는 코드는 현재 확인되지 않았다. 완료 상태를 압력만으로 해제하는 구현도 확인되지 않았다.

### 4-3. 주의할 조기 종료 경로

전진 시작 직후 '압력이 이미 기준 이상'인 분기에서는 전진 종료 함수를 호출하고 현재 사이클 함수를 즉시 반환한다. 이 경우 해당 사이클 마지막의 공통 축 상태 점검은 실행되지 않는다.

다만 **전진 종료 함수 자체가 완료 상태를 직접 기록**하므로, '상태 점검 한 주기 생략'만으로 완료 신호가 고착된다고 판단하면 안 된다.

## 5. 오프셋과 압력 허용오차는 다른 값

| 설정 개념 | 코드상 역할 |
| --- | --- |
| 승압 설정압력 | 터치압력 완료 비교 기준 |
| 압력 허용오차 | 승압 판정의 허용 범위를 낮추는 값 |
| 전진 거리 오프셋 | 특정 위치센서 경로에서 전진 프로파일 목표 위치 변경 |
| 위치 허용오차 | 전진 목표 위치와 실제 위치의 허용 범위 |
| 축 센서 방식 | 완료 상태 재판정 방식 결정 |

현장 담당자가 변경한 '노즐 오프셋'이 **전진 거리 오프셋인지 압력 허용오차인지 미확인**이다. 전진 거리 오프셋이라면 압력 비교 및 완료 상태 해제 논리를 직접 변경하지 않는다.

## 6. 실제 신호를 기준으로 한 분기별 진단

| 온라인 관찰 | 해석 방향 |
| --- | --- |
| 내부 축 Status가 NEG_END 유지, 전진 완료 출력도 ON | 센서 타입 및 완료 상태 해제 조건 검토 |
| 후퇴 시작 명령이 들어오나 후퇴 단계로 진입하지 않음 | 후퇴 시작 인터록/명령 경로 검토 |
| 후퇴 단계로 진입하며 Status가 POS_MOVEMENT로 변경 | 내부 완료 상태는 정상 변경. HMI/외부 완료 출력의 별도 매핑 검토 |
| 실제 위치나 리미트 입력은 변했지만 Status가 유지 | 센서 타입 선택 및 상태 점검 분기 확인 |
| 화면 압력은 170 bar이나 PLC 내부 압력과 다름 | 데이터 원본/스케일/표시 동기화부터 확인 |

## 7. 온라인 로그 최소 항목

노즐 전진 → 터치 완료 → 후퇴 시작 → 완료 해제 구간에 대해 다음 항목을 **동일 시간축**으로 취득한다.

- 노즐 축 센서 타입의 설정값과 실제 사용값
- 노즐 축 실제 압력, 승압 설정압력, 압력 허용오차
- 노즐 축 실제 위치, 전진 목표 위치, 위치 허용오차
- 축 Status, 제어 STEP, 전진/후퇴 Start·Stop·Active
- 전진/후퇴 리미트 입력과 전진/후퇴 밸브 명령
- HMI 전진완료 표시 및 실제 외부 완료 출력 매핑(존재 시)
- 노즐 압력센서 사용 옵션, 펌프 번호 및 압력 피드백 원본

실장비 테스트는 승인된 정비 절차 아래에서 진행하며 안전 인터록 우회나 출력 강제는 수행하지 않는다.

## 8. 분석 결론 및 미확정 사항

**코드에서 직접 확인된 것**
- 노즐 화면은 축 제어 데이터를 복사해 표시한다.
- 노즐 압력 피드백은 전용 센서 또는 지정 펌프 압력에서 선택된다.
- 전진 종료 함수가 정상 종료 시 전진완료 축 상태를 설정한다.
- 완료 해제는 센서 타입/위치/디지털 입력/후퇴 시퀀스의 영향을 받으며 단순 압력 감소에 직접 연동된 것으로 보이지 않는다.
- 후퇴 초기화 함수는 축 상태를 '후퇴 중'으로 변경한다.

**아직 확인되지 않은 것**
- 실제 현장 설비의 노즐 센서 타입 및 노즐 압력센서 사용 옵션
- 현장에서 말한 '전진완료'가 내부 축 상태, 화면 표시, 외부 출력 중 무엇인지
- 170 bar의 압력 피드백 측정 지점과 160 bar 설정값의 실제 연결 관계
- 후퇴 명령이 들어갔는지 및 실제 노즐이 후퇴하는지
- 10/30 압력 저하와 11/02 완료 신호 미해제 사이의 인과관계

> 원인 부품 확정 및 PLC 수정은 보류. 현재 문서는 **검증 전 논리 분석**으로 관리한다.
