# 01. 문제 인식 — 노즐 터치압력 저하 및 전진완료 신호 미해제

> 기록 범위: 2026-10-30 ~ 2026-11-02  
> 대상: 2019년식 유압식 사출기(설비·고객 식별정보 비공개)  
> 상태: **원인 미확정 / 유압계통 및 PLC 완료판정 분리 분석 중**  
> 자료: 현장 통화·메신저 보고 및 제어 코드 검토

## 1. 핵심 문제 정의

동일한 노즐 터치압력 설정(현장 진술상 175 bar)에 대해 설비 초기에는 실제 압력이 약 175 bar까지 형성됐으나, 약 7년간 최대 도달 압력이 점진적으로 낮아졌다고 보고되었다. 2026-10-30 확인 시에는 약 141 bar로 보고되었다. 압력 저하에도 생산이 가능하여 사용을 지속했지만, 최근 사출 중 노즐 후퇴·수지 누출과 미성형 및 불량률 증가로 정상 생산이 어려워졌다.

별개로 2026-11-02에는 **노즐 전진완료 신호가 해제되지 않는다**는 현장 문의가 접수되었다. 이때 전달된 값은 현재 압력 약 170 bar, 전진완료 기준 약 160 bar이며, 노즐 오프셋값 조정에도 개선되지 않았다고 한다.

**두 현상을 동일 고장으로 확정하지 않는다.** 특히 10/30의 141 bar와 11/02의 170 bar가 동일 센서·동일 동작 단계·동일 설정 조건에서 취득된 값인지는 확인되지 않았다.

## 2. 경과 및 확인사항

| 일자/시기 | 구분 | 내용 | 근거 수준 |
| --- | --- | --- | --- |
| 2019년경 | 과거 상태 | 노즐 터치압력 설정 175 bar, 실제 도달도 약 175 bar였다고 함 | 현장 진술 |
| 2019~2026년 | 성능 변화 | 약 7년에 걸쳐 도달 압력이 점진적으로 감소. 초기에는 생산 가능 | 현장 진술 |
| 2026-10-30 | 생산 불량 | 현재 약 141 bar까지 형성, 사출 시 노즐이 뒤로 밀리고 수지 누출·미성형 증가 | 현장 통화 |
| 2026-10-30 | 압력 확인 | 현장 아날로그 압력계와 화면 표시가 같은 수준이라고 보고 | 현장 통화 |
| 2026-10-30 | 펌프 확인 | 펌프 1·2 강제 펌핑 시 메인 유압 상승은 정상이라고 보고 | 현장 통화 |
| 2026-10-30 | 누유 확인 | 외부 유압유 누유 발견되지 않았다고 보고 | 현장 통화 |
| 2026-10-30 | 체크밸브 | 탈거·확인 후 체크밸브 교체했으나 증상 동일 | 현장 통화 |
| 2026-11-02 | 추가 증상 | 현재 압력 약 170 bar, 전진완료 기준 약 160 bar. 전진완료 신호 미해제 및 오프셋 조정 효과 없음 | 메신저 보고 |

**압력 구분:** 이 기록의 175/141/170 bar는 현장 대화에서 노즐 터치압력으로 설명된 수치다. 사출압력·배압·메인 유압과 혼용하지 않는다. 다만 표시 압력의 측정 지점 및 170 bar의 시험 조건은 실장비 확인이 필요하다.

## 3. 현재 문제를 두 갈래로 분리

### A. 유압/기계 계통 — 압력 형성 능력 저하 및 노즐 밀림

- 장기적인 성능 저하가 있었다는 점에서 부품 마모, 밸브의 내부 누설 또는 제어 성능 저하를 고려한다.
- 외부 누유가 없다는 사실만으로 **밸브·실린더 내부 누설**을 배제할 수 없다.
- 체크밸브는 교체 후에도 동일 증상이어서 해당 부품 단독 고장 가능성이 낮아졌다.
- 릴리프·감압·압력제어밸브, 방향제어밸브, 노즐 터치 실린더 및 부하 조건별 유압 상태는 아직 검증되지 않았다.
- 펌프 강제 펌핑 정상은 기본 압력 형성의 근거일 뿐, 해당 작동 회로의 실제 부하 조건까지 정상이라는 확증은 아니다.

### B. PLC/신호 계통 — 노즐 전진완료가 OFF되지 않음

- 현장 보고: 현재 압력 약 170 bar, 완료 기준 약 160 bar, 오프셋 조정 후에도 완료 신호가 유지된다고 함.
- **실제 전진완료 신호의 정의(내부 축 상태/HMI 표시/외부 출력)**가 아직 특정되지 않았다.
- 실제 노즐이 후퇴했는데 완료 표시만 남는지, 후퇴 명령 자체가 실행되지 않는지도 확인되지 않았다.
- 코드상 노즐 전진 종료 시 완료 상태를 설정하고, 센서 방식·후퇴 시퀀스에 따라 해제하는 구조가 발견되었다. 자세한 내용은 [02_해당코드_논리분석.md](02_해당코드_논리분석.md) 참조.

## 4. 원인 가설과 검증 현황

| 가설 | 현재 판단 | 추가 확인 |
| --- | --- | --- |
| 체크밸브 자체 불량 | 교체 후 동일 → 우선순위 하향 | 부품 규격·장착 일치 여부가 불명확하면 별도 확인 |
| 릴리프/감압/압력제어밸브 열화 | 가능성 있음, 미확정 | 밸브 위치, 설정, 작동 시 압력·내부 누설 |
| 노즐 터치 실린더 내부 누설 | 가능성 있음, 미확정 | 지정 절차에 따른 유지력·내부 누설 검사 |
| PLC 완료 상태의 유지 특성 | 코드상 가능성 확인 | 센서 방식, 내부 Status 및 외부 완료신호 매핑 |
| PLC 설정/오프셋 오류 | 아직 미확정 | 오프셋 종류(위치/압력), 실제 적용 조건 |

## 5. 다음 검증에 필요한 증거

1. **유압:** 노즐 동작 중 메인 압력과 노즐 터치 회로 압력의 측정 지점·시험 조건·시간 변화 기록.
2. **PLC:** 노즐 축 센서 타입, 실제 압력, 압력 목표·허용오차, 실제 위치·위치 허용오차, 제어 STEP, 축 Status, 전진·후퇴 시작 명령, 완료 신호의 실제 출력 경로.
3. **시퀀스:** 전진 → 터치 완료 → 후퇴 명령 → 완료 해제 과정을 같은 시간축에서 비교.
4. **설정 변화:** 10/30의 141 bar와 11/02의 170 bar 사이 작업 이력 및 시험 조건 확인.

## 6. 현재 결론

- **확인된 현상:** 장기적인 노즐 터치압력 도달 성능 저하, 최근 생산 불량 증가, 체크밸브 교체 후 개선 없음, 전진완료 신호 미해제 추가 보고.
- **유력하지만 미확정:** 유압회로의 성능 열화와 PLC 축 상태의 완료 유지 특성.
- **금지할 단정:** 릴리프밸브 불량 확정, PLC 버그 확정, 170 bar까지 회복되었다는 확정, 두 증상의 단일 원인 확정.

> 정비·측정은 유압 잔압 및 설비 안전 상태를 확인한 후 시행한다. PLC 출력 강제, 안전 인터록 우회, 임의 압력 상향은 검증 방법으로 사용하지 않는다.
