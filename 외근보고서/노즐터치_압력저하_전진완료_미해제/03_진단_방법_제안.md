# 03. 진단 방법 제안 — 노즐 터치압력 저하 및 전진완료 미해제

> 작성일: 2026-11-02  
> 목적: 확인된 현장 증상과 PLC 정적 분석에 근거해 **실장비 검증 절차·필요 데이터·판정 기준**을 제안한다.  
> 상태: **진단 계획 수립 / 현장 실측 미실시 / 원인 미확정**  
> 연계: [01_문제인식.md](01_문제인식.md) · [02_해당코드_논리분석.md](02_해당코드_논리분석.md)  
> 공개 범위: 고객사·설비 식별정보와 회사 원본 코드는 제외하고 제어 논리 및 검사 방법만 서술한다.

## 1. 진단 목표 및 원칙

### 1-1. 서로 다른 두 문제를 분리

| 구분 | 보고된 증상 | 현재 근거 | 검증 목표 |
| --- | --- | --- | --- |
| A. 유압/기계 | 약 7년 동안 노즐 터치압력 도달값이 175 → 141 bar 수준으로 점진적 하락, 최근 노즐 밀림·수지 누출·미성형 증가 | 현장 진술, 체크밸브 교체 후 동일 | 실제 압력 생성·유지·기계적 접촉력의 이상 부위 구분 |
| B. PLC/신호 | 11/02 현재 약 170 bar, 전진완료 기준 약 160 bar에서 '전진완료가 안 떨어짐', 오프셋 조정 후에도 동일 | 현장 메신저, 완료 상태 SET/RESET 코드 분석 | 해당 '전진완료'의 정확한 신호와 유지 이유 규명 |

- **A와 B가 같은 고장이라고 미리 결론 내리지 않는다.**
- 141 bar와 170 bar가 **동일 측정 지점·동일 설정·동일 동작 단계**의 수치인지 먼저 확인한다.
- 설정 160 bar가 실제로 노즐 승압 설정압력인지, 표시되는 전진완료 기준인지, 다른 내부 파라미터인지 확정한다.
- 현재 압력 170 bar > 완료 기준 160 bar라면 **압력 조건은 충족**할 수 있다. '압력이 높으므로 완료가 해제되어야 한다'는 판단은 성립하지 않는다. 전진완료 해제는 센서 방식과 후퇴 상태 전이를 별도 검토한다.
- 유압 측정/정비는 현장 안전 절차와 장비 제조사 지침에 따른다. **안전 인터록 우회, 임의 출력 강제, 릴리프 압력 상향, 잔압 상태의 밸브·배관 분해는 금지**한다.

## 2. 진단 착수 전 확인할 사항

기계팀·현장 담당자와 아래 내용을 먼저 맞춘다. 이는 시험 조건이 달라 오진하는 일을 방지하기 위한 절차다.

1. **압력 구분**: 175/141/170 bar가 각각 노즐 터치압력인지, 메인 펌프압인지, 화면 및 외부 계기 측정 위치가 어디인지 기록.
2. **시험 조건**: 금형 체결 여부, 노즐 전진/접촉/사출/후퇴 중 어느 시점인지, 설정 레시피, 유압유 온도, 현재 운전 모드 기록.
3. **전진완료의 의미**: HMI 램프, 내부 축 상태, 물리 입력 또는 외부 완료 출력 중 무엇이 '안 떨어지는지' 특정.
4. **물리 동작**: 완료 신호가 유지된 동안 노즐이 실제로 전진 접촉 중이었는지, 후퇴 명령을 줬는지, 후퇴가 실제 발생했는지.
5. **정비 이력**: 141 → 170 bar 보고 사이의 밸브 교체, 설정 변경, 배관/센서 작업 및 측정 조건 차이 확인.

## 3. 1차 — PLC 온라인 읽기 전용 진단

**목적:** 완료 판정 로직이 실제 어떤 분기로 동작하는지, 전진완료가 어느 상태에서 유지되는지 확인한다. 원인 파악 전까지 변수 강제 및 프로그램 변경을 하지 않는다.

### 3-1. 먼저 상수·신호 정의 확인

- 노즐 이동축의 실제 인덱스(`S_IU`)를 정의 파일에서 확인. 화면 압력으로 알려진 `Ax[12]`와 같은 축이라는 점은 최종 대조 필요.
- 전진완료 실제 표시/출력 변수에 대한 Cross Reference 확보. `AXdat[S_IU].Status == AX_STAT_NEG_END_POSITION`이 외부 완료 신호를 직접 제어하는지는 아직 미확인.
- `IU_FIX.GEN.SSensorType` 초기 설정값과 현재 `AXdat[S_IU].SensorType` 일치 여부 확인.
- `CSTM_FIX.Para[S_CSTM_FIX_NOZZLE_PRESSURESENSOR_USE]` 값으로 노즐 축 실제 압력 피드백 소스 확인.
- `tk1i.c`의 **조건부 압력 감시 기능**이 사용하는 옵션·Min/Max·정상 플래그와 `alarm.c`의 **노즐압력 이상 알람**이 실제 설비에서 활성화되어 있는지 확인.
- 알람 기본값에는 즉시 자동정지(AUTOSTP)가 포함되지만 실제 설정 배열은 유지형이므로 `AL_FIX[S_ALARM_NOZZLEPRS_ABNORMAL]`의 온라인 값을 별도 확인.
- 노즐 전진 시작 시 **이미 압력이 기준 이상이어서 `ExitMoveNeg()`로 바로 끝나는 경로**가 실제로 발생하는지 확인.

### 3-2. 온라인 데이터 수집 항목

> 아래는 **코드 분석으로 확인한 내부 변수 후보**다. 온라인 프로젝트의 심볼 노출 여부에 따라 실제 경로를 확인해 사용한다. `S_IU`는 상수 정의를 검증한 후 실제 인덱스로 치환한다.

| 그룹 | 핵심 변수·신호 | 수집 목적 |
| --- | --- | --- |
| 센서 방식 | `IU_FIX.GEN.SSensorType`, `AXdat[S_IU].SensorType` | 완료 상태 재판정 분기 확정 |
| 압력 원본 | `CSTM_FIX.Para[S_CSTM_FIX_NOZZLE_PRESSURESENSOR_USE]`, `AXdat[S_IU].PhyIn.ApDig`, `AXdat[S_IU].Ap` | 전용 압력 센서 사용 여부 및 실제값 |
| 펌프 피드백 | `AXdat[S_IU].PmpNr`, `PUdat[해당 펌프].Ap` | 노즐 축 압력의 펌프 참조 경로 확인 |
| 압력 기준 | `IU_PAR.NEG.SpNP`, `IU_FIX.NEG.Sptol`, `AXdat[S_IU].Sp_act` | 설정압력·허용오차·실제 압력 지령 비교 |
| 위치 조건 | `AXdat[S_IU].As`, `REC_DATA.IU.NEG.Ss[0]`, `IU_FIX.NEG.Sstol`, `IU_PAR.NEG.SsNP` | 목표 위치/위치 허용차/거리 오프셋 검증 |
| 상태 전이 | `AXdat[S_IU].CtrStep`, `AXdat[S_IU].Status`, `AXdat[S_IU].NEG.Con.Status`, `AXdat[S_IU].POS.Con.Status` | 전진→승압→정지→후퇴 단계 파악 |
| 명령·입력 | `AXdat[S_IU].NEG.Con.Start/Stop`, `AXdat[S_IU].POS.Con.Start/Stop`, `AXdat[S_IU].PhyIn.negDI1/posDI1` | 명령 수신 및 완료센서 입력과 비교 |
| 실제 출력 | `AXdat[S_IU].PhyOut.negDO1/posDO1` | 밸브 지령 상태 확인(읽기 전용) |
| 판정 신호 | 실제 HMI 전진완료·외부 완료신호(매핑 확인 후 추가) | 내부 상태와 표시/출력 불일치 확인 |
| 압력 감시 설정 | `REC_DATA.AUT.SbNozzlePressureMonitoringUse`, `REC_DATA.AUT.NozzleTouchPressureMin/Max` | 옵션 ON/OFF 및 상·하한 적정성 확인 |
| 감시 결과 | `MA_STAT.AbNozzleTouchPrsNormal`, `MMI_DATA.Mode` | 압력 이상 때 감시 결과가 0으로 내려가는지 확인 |
| 알람/정지 | `AL_FIX[S_ALARM_NOZZLEPRS_ABNORMAL]`, 해당 알람 상태·시간, `MMI_DATA.ModeReq` | 알람 SET 및 자동정지 반응과 리셋 경로 확인 |
| 유지 제어 여부 | `AXdat[S_IU].PmpReq.Req`, `AXdat[S_IU].PmpReq.Sp_scal/SQ_scal`, `AXdat[S_IU].Sp_act/SQ_act` | 완료 전후 펌프 요청 및 출력 재활성 여부 확인 |
| 시험 경과 | 유압유 온도, 운전 경과 시간, 생산 사이클 수 | 초기 정상과 반복 운전 후 이상 비교 |

**단위 주의:** 코드에 압력값의 내부 단위를 0.1 bar로 설명하는 부분이 있다. 화면 bar 수치와 내부 저장값을 그대로 수치 비교하지 말고 프로젝트에서 적용되는 스케일을 함께 기록한다.

### 3-3. 수집 구간 및 방식

설비가 안전하게 운전 가능한 상황에서, 현장 담당자가 승인한 정상 시퀀스의 **읽기 전용 TRACE/온라인 모니터링**을 수집한다.

```text
T0  전진 명령 수신
T1  노즐 전진 동작 / 압력 상승
T2  전진완료 판정 또는 승압 지연
T3  전진 종료 / 완료 신호 ON
T4  정상 후퇴 명령
T5  후퇴 동작 시작 / 내부 Status 변화
T6  완료 신호 OFF / 실제 후퇴 확인
```

- 모든 데이터는 같은 시간축으로 기록하고, 상태 전이 직전·직후의 값을 보존한다.
- 가능하면 제어 원본인 `AXdat`을 사용하고, 100 ms 주기의 MMI 복사값만으로 짧은 STEP 전이를 판단하지 않는다.
- 주기/샘플링 간격은 실제 PLC 태스크 주기와 TRACE 부하를 고려해 선정한다. 샘플 손실 여부도 기록한다.
- 재현 시험이 위험하다면 정상 주기에서 남는 이벤트 로그와 기록 가능한 신호로 진단하며 위험한 운전 재현을 강요하지 않는다.
- '처음에는 정상, 일정 시간 후 이상' 제보를 검증하려면 **동일 설비·동일 레시피·가능한 동일 금형/작업 조건**에서 초기 정상 구간과 이상 직전 구간의 유온·압력·Status·알람을 비교한다. 여러 현장 제보는 증거 수집 전까지 별개 사례로 다룬다.

## 4. 2차 — 전진완료 신호 분기별 판정

| 관찰 결과 | 우선 해석 | 다음 확인 |
| --- | --- | --- |
| 실제 압력 ≥ 승압 판정값, 내부 `Status=NEG_END`, 물리적 노즐 접촉 유지 | 코드상 정상 완료 상태일 가능성 | 완료 OFF를 요구한 실제 운전 조건과 요구 사양 확인 |
| 후퇴 명령은 접수됐으나 `CtrStep`이 후퇴(POS) 단계로 바뀌지 않음 | 후퇴 명령 경로/인터록/상태기계 진입 문제 | 후퇴 Start, 현재 CtrStep, 운전 모드·인터록 |
| 후퇴 단계 진입 후 `Status=POS_MOVEMENT`으로 바뀌나 HMI/외부 완료는 ON | 내부 완료 상태가 아닌 표시/출력 매핑 문제 가능 | 실제 신호 대입·래치·통신 경로 Cross Reference |
| 전진완료 상태 유지 중 위치가 목표 허용범위를 이탈함 | 위치센서 방식이라면 재판정이 필요한 상황 | 센서 타입·온라인 실제 위치·`CheckAxStatus` 실행 경로 |
| 전진 센서 OFF 후에도 `Status=NEG_END` 유지 | 디지털 센서 방식/MoveMode/입력 경로 확인 필요 | SensorType, MoveMode, `PhyIn.negDI1` |
| 압력이 설정값 아래로 내려갔으나 완료 상태 유지 | **압력만으로 완료 상태를 해제하는 코드가 현재 확인되지 않아 설계상 가능** | 센서 타입과 후퇴/재판정 조건 확인 |
| 전진 시작 시 압력이 이미 판정 기준 이상이고 곧바로 종료 | 조기 `ExitMoveNeg` 경로 가능 | 해당 스캔의 CtrStep, 압력, Stop/IStop, 이후 Status |
| 전진완료 후 측정압력 이상인데 감시 플래그 1 | 감시 옵션 OFF·모드 불일치·완료 상태 미성립·잘못된 압력원 가능 | MonitoringUse, Mode, Status, Min/Max 및 전용 센서 옵션 |
| 감시 플래그 0과 노즐압력 알람 SET 확인 | 압력 이상 감지·알람 경로 동작 | 실제 AUTOSTP 설정, 운전 정지 시점, 알람 이력 |
| 압력 정상 회복 후에도 알람 유지 | 해당 분기 자동 RESET 비활성 또는 알람 래치 가능성 | 승인된 알람 확인·리셋 절차 및 다른 처리 경로 |

추가 확인할 핵심 코드 관계:
- 전진 초기화: `InitMoveNeg()` → 축 상태를 전진 중으로 설정.
- 정상 전진 종료: `ExitMoveNeg()` → 조건에 따라 축 상태를 전진완료로 설정.
- 후퇴 초기화: `InitMovePos()` → 축 상태를 후퇴 중으로 변경.
- 상태 점검: `CheckAxStatus()` → 센서 종류에 따라 위치·디지털 입력을 사용해 완료 상태를 재판정.
- 일부 센서 타입(시간/압력 방식)은 공통 상태 점검에 별도 분기가 없어 **이 함수만으로** 완료가 해제되지 않을 수 있다. 단, 다른 로직 및 신호 매핑 확인 전에는 고장 확정 불가.

## 5. 3차 — 압력 감시·알람·자동정지 실제 동작 검증

**근거:** 정적 코드 분석에서 `tk1i.c`의 압력 감시 플래그 생성과 `alarm.c`의 이상 알람 SET 경로를 확인했다. **기능이 존재한다는 사실과 해당 설비에서 실제로 동작한다는 사실을 구분**한다.

### 5-1. 조건별 관찰·기대값

| 조건 | 코드상 기대 | 현장 검증 |
| --- | --- | --- |
| 감시 옵션 OFF | 정상 플래그 = 1 | 사용 옵션이 실제로 OFF인지 기록 |
| 감시 옵션 ON, 자동/반자동 아니거나 전진완료 아님 | 정상 플래그 = 1 | 실제 모드·상태와 일치하는지 기록 |
| 감시 옵션 ON + 자동/반자동 + 전진완료 + 압력 허용범위 내 | 정상 플래그 = 1 | 압력 단위/Min/Max 스케일 검증 |
| 위 감시 조건이 성립하고 압력 허용범위 이탈 | 정상 플래그 = 0 → 알람 SET 대상 | 동일 시간축에서 플래그·알람 상태 비교 |
| 알람 SET + 현장 `AL_FIX`에 AUTOSTP 활성 | 자동운전 정지 요청 | `MMI_DATA.ModeReq`과 실제 운전 모드 확인 |
| 압력이 다시 정상으로 돌아옴 | 감시 플래그는 정상(1) 회복 가능, 해당 알람 분기 자동 RESET 주석 처리 | 알람이 유지되는지·승인된 리셋/ACK 경로 확인 |

**주의:** 이상 상태를 인위적으로 만들기 위해 압력 하한을 높이거나 안전 기능을 끄지 않는다. 가능한 경우 기존 이상 이력, 정상 생산 중 안전하게 취득되는 수동 측정·읽기 전용 TRACE를 활용한다.

### 5-2. 감시와 유지제어를 분리해서 판단

- **감시:** 압력 허용범위 비교 및 알람 발생 가능성을 의미한다.
- **유지제어:** 노즐 접촉력 유지를 위해 완료 이후 재승압 요청이나 밸브 제어가 실제 발생하는지 의미한다.
- 완료 상태에서 축의 펌프 요청이 0이라는 사실은 코드로 확인했지만, 실제 압력이 0이 되거나 유압 잠금이 해제된다고 해석하면 안 된다.
- 완료 이후 별도의 재승압이 발견되지 않았다는 것은 현재 분석한 경로에 국한되며 **유압회로·다른 태스크의 기능 부재를 확정하지 않는다.**

### 5-3. 원인 가설 검증/반증 기준

| 가설 | 지지하는 관찰 | 반증 또는 재검토하는 관찰 |
| --- | --- | --- |
| 완료 이후 감시가 비활성 | MonitoringUse=0 또는 조건 미성립 | 옵션 ON·조건 성립 중 플래그와 알람이 정상 반응 |
| 완료 상태는 유지되나 실제 접촉력 하락 | 전진완료 Status 유지 + 독립 계측의 접촉 유지력/노즐 압력 저하 | 독립 계측상 접촉력 정상·노즐 후퇴 없음 |
| 압력 감시 후 재승압 없음 | 완료 이후 요청/밸브 출력 재가동 없음 + 유압회로도와 일치 | 다른 태스크에서 명시적 재승압 또는 회로상 능동 유지 확인 |
| 일시 압력 이상 알람이 지속 | 이상 구간에 알람 SET 후 플래그 정상 복귀, 알람 유지 | 별도 RESET 처리로 알람 정상 해제 |
| 장시간 운전 영향 | 유온/운전 시간 상승에 따라 재현 조건과 계측 변화 반복 | 동일 조건에서 시간 의존성·경향 없음 |

## 6. 4차 — 유압/기계 계통 진단 제안

**목적:** 장기간의 노즐 터치압력 도달 성능 저하를 공급측 문제와 노즐 분기 회로/기계적 유지력 문제로 분리한다. 기계·유압 담당자가 제조사 회로도와 정비 절차에 따라 수행한다.

### 6-1. 비교 측정 계획

| 비교 지점 | 기록할 내용 | 목적 |
| --- | --- | --- |
| 메인 펌프압(지정된 측정 포트) | 노즐 전진·접촉·유지 단계별 압력 추이 | 공급측 압력 형성 여부 |
| 노즐 터치 분기 압력(지정된 측정 포트, 존재 시) | 같은 시점의 압력 변화 및 최대 도달값 | 분기 회로 압력 손실/제한 여부 |
| PLC의 노즐 축 압력 피드백 | 내부 원본과 화면·현장 계기 비교 | 센서·스케일·측정 지점 혼동 제거 |
| 노즐 전진 위치 또는 실제 기계 움직임 | 사출 전후 접촉 유지 여부 | 접촉력 유지 불량과 사출 중 밀림의 관계 |

**해석 시 주의:** 펌프 강제 운전에서 메인 압력이 정상이라는 과거 진술만으로 실제 노즐 부하 시 압력 공급이 정상이라고 단정하지 않는다. 또한 서로 다른 측정 포트의 압력은 회로 구조와 유량 조건을 고려해야 한다.

### 6-2. 결과별 다음 조사 대상

| 측정 결과 | 우선 점검 계통 |
| --- | --- |
| 실제 노즐 동작에서 메인 압력부터 부족 | 펌프 제어 지령, 압력제어 계통, 운전 시 부하·유량 및 공급 성능 |
| 메인 압력 정상, 노즐 분기 회로에서만 부족 | 해당 분기의 릴리프·감압·방향제어밸브 및 내부 누설 경로 |
| 압력 형성은 되나 유지 중 접촉력/위치 저하 | 해당 회로의 유지 밸브, 실린더 내부 누설, 기계적 접촉 구조 |
| 유압 계측 정상인데 PLC 압력만 다름 | 압력 센서, 배선, 입력 스케일, 실제 참조 압력원 |
| 체크밸브 교체 후 증상 불변 | 동일 부품 자체 불량 가능성 감소. 회로도 기준 다른 밸브·실린더로 범위 확대 |

- **릴리프밸브/감압밸브:** 조기 개방·설정 이탈·내부 누설 가능성 검토. 해당 밸브가 실제 문제 회로에 존재하는지부터 확인.
- **방향제어밸브:** 스풀/시트 누설 및 동작 상태 검토.
- **노즐 터치 실린더:** 피스톤 씰 내부 누설, 기계적 유지력·기구 상태 점검.
- **체크밸브:** 신품 교체 후 동일하므로 우선순위를 낮추되, 규격/장착 방향/적용 회로 확인은 유지.

## 8. 진단 성공 기준과 후속 의사결정

다음 조건을 만족할 때 진단을 종료하고 원인확정/조치 문서로 넘어간다.

1. '전진완료 미해제'의 대상 신호를 식별하고, **내부 상태 → HMI/외부 출력** 경로를 확인한다.
2. 노즐 센서 타입·압력원·오프셋의 실제 설정값을 확보하고, 전진/후퇴 시퀀스 로그로 완료 상태 유지 이유를 설명한다.
3. 감시 옵션·상하한·정상 플래그·노즐압력 알람·AUTOSTP 실제 설정을 확인하고, 압력 이상 시 감지/정지와 압력 유지 기능을 구분해 설명한다.
4. 압력 저하에 대해 **공급측/노즐 분기측/실린더·기계측 중 어느 경로가 원인인지** 계측 근거를 확보한다.
5. 가능하면 조건을 변경하지 않은 비교 시험을 수행하며, 141 bar와 170 bar의 조건 차이를 설명한다.
6. 수리 또는 프로그램 수정이 필요한 경우 제조사 기준·안전검토·영향 범위를 검증한 뒤 별도 승인 절차를 따른다.

## 9. 즉시 요청할 현장 자료

**PLC 담당에게:** 축 번호 정의, 센서 타입, 원본 압력 및 설정값, CtrStep/Status, 후퇴 Start/Stop, 실제 전진완료 표시/출력 매핑, **압력 감시 옵션·Min/Max·정상 플래그·알람 실제 설정과 발생 이력**, 동일 시간축 TRACE, 최초 정상/시간 경과 이상 비교 자료.

**기계팀에게:** 노즐 터치 유압회로도, 압력 측정 포트 정보, 메인/노즐 분기 압력 비교 결과, 체크밸브 교체 내역, 릴리프·감압·방향제어밸브 및 실린더 점검 결과.

**현재 판정:** 감시·알람 기능은 코드로 확인됐으나 실제 설비에서의 사용·동작은 미검증이다. 진단 방법 제안 단계이며 **원인 확정 및 코드 수정 없음.**
